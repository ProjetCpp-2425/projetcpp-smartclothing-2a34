👗 **Fashion Store Management System (C++ / Qt / Arduino)**

Fashion Store Management System is a desktop application built with C++ and Qt, integrated with Arduino hardware to manage store operations. The system supports CRUD for admin, employees, clients, products, and transactions, along with security, analytics, and IoT features.

🚀** Key Features**
🏢 **Admin & Employees**

CRUD operations for admin and employees

Search, sort, and statistics

PDF and Excel report generation

Login with password recovery

SMS notifications via Twilio

👗 **Products (Fashion Clothes)**

Full CRUD operations for products

Integrated chatbot for product queries

Find, sort, and statistics

👥 **Clients**

CRUD and VIP selection

Track purchase history and engagement

💳 **Transactions**

CRUD operations

Transaction history tracking

PDF/Excel export of transactions

🤖 **Arduino Integration**

Custom keyboard input for secure password entry

Detect client entrance and exit from store

RGB light display for VIP client names
